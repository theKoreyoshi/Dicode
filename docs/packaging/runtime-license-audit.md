# Codex Runtime 分发许可核查报告

## 核查结论

结论：满足指定条件后可分发（待权利方最终确认）

## 证据与依据

1. 开源代码许可证：官方仓库 `github.com/openai/codex` 根目录 LICENSE 为 Apache
   License 2.0（已联网核查原文）。Apache 2.0 第 2 条授予以 Source 或 Object 形式
   复制、制作衍生作品、再分发的权利（含二进制形式）。
2. 预编译二进制：官方预编译 codex.exe 的组件构成未在安装目录附带 LICENSE/NOTICE，
   无法确认是否完全由 Apache 2.0 覆盖的组件构成。
3. 商标与品牌：Apache 2.0 不授予任何商标权（第 6 条），不得暗示 OpenAI 对 Dicode 的
   背书。
4. 版本状态：当前为 `0.167.0-alpha.3.2`（alpha 预发布），非稳定正式版本。

## 分发条件（必须同时满足）

1. 使用稳定正式版本的 Codex，而非 alpha 预发布版本。
2. 随包附带 Apache 2.0 许可证全文与版权声明（NOTICE）。
3. 确认官方预编译二进制的第三方组件与 NOTICE 声明。
4. 不使用可能暗示 OpenAI 背书 Dicode 的商标/品牌表述。
5. 不修改 Codex Runtime 二进制；如有修改，遵循 Apache 2.0 衍生作品义务。

## 尚需权利方确认的项

- 官方预编译二进制的完整组件构成与第三方许可证声明（NOTICE）。
- 是否允许将 Codex 作为产品名的一部分用于商业分发（商标问题）。

## 结论演进

- 阶段 6：标记为阻塞（待人工确认）。
- 阶段 6.1：核查到官方 LICENSE 为 Apache 2.0，结论升级为满足指定条件后可分发，
  但仍需权利方对二进制组件与商标做最终确认。
