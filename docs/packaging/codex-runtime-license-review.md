# Codex Runtime 许可证审查

## Apache License 2.0

官方仓库根目录 LICENSE 为 Apache 2.0。第 2 条授予以 Source/Object 形式复制与再分发；
第 4 条要求再分发时附带许可证副本、保留版权/NOTICE、标注修改；第 6 条不授予商标权；
第 7 条为免责声明。

## 对 Dicode 分发的分析

- 源码再分发：Apache 2.0 明确授权。
- 二进制再分发：Apache 2.0 亦授权 Object 形式，但要求附带 LICENSE/NOTICE 与版权声明。
- 官方预编译包：未附带 LICENSE/NOTICE/SBOM，无法确认其全部组件均受 Apache 2.0 覆盖。
- 商标：Apache 2.0 不授予「Codex」商标，Dicode 不得暗示 OpenAI 背书。

## 待确认项

- 官方预编译二进制的第三方依赖许可证清单（NOTICE/SBOM）。
- 是否存在未以 Apache 2.0 覆盖的专有组件。
- 商标与产品名使用边界。

本报告为技术初步审查，不替代公司法务或权利方书面意见。
